# One Letter for Your Day — Z

An entry for the make.fun bounty [One Letter for Your Day](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36).

The entry is a single letter: **Z**. It stands for the hidden word **"zero sleep"** — the diary of a day that ran on no rest at all. A lone Z reads as the cartoon snore, the end of the alphabet, and the honest admission that today was survived, not slept through. Vivid, funny, and true to a real day.

`main.py` writes exactly that one byte, `Z`, to `/output/entry.txt` — no word, no gloss, no punctuation, and no trailing newline (a newline would make the file 2 characters and fail the gate). It then reads the file back and asserts it is exactly 1 character. Python 3 standard library only; deterministic, no network, no randomness, no wall-clock use.

## Run it

```sh
python3 main.py
```

After running, `/output/entry.txt` holds exactly one byte: `Z`.
